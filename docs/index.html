Elevance Health EDS Migration

Tracking the migration of Elevance Health provider and member sites to Adobe Edge Delivery Services (EDS), authored through Document Authoring (DA). This page summarizes where the project stands, recent work, the current sprint scope, and the block library available for building pages.

Where things stand In progress

The project uses two Document Authoring sites — elevance and elevance-nc — served from a single GitHub repository (shared blocks, styles, and scripts; repoless, no fstab.yaml). The Healthy Blue NC provider site (elevance-nc) is fully imported: the home page plus 46 interior pages (47 URLs), with nav and footer fragments, the north-carolina theme, and 35 blocks. It is published to both preview and live, and work is now in visual-parity QA — page-by-page fixes for spacing, link styling, and broken source links tracked in GitHub issues. The elevance (GRS provider) site has a preview home page and an importer, but nothing is published to live yet.

Status. Current DA mapping: elevance → GRS provider (provider.bluemedadvgrhs.com/grs-provider) and elevance-nc → Healthy Blue NC provider (provider.healthybluenc.com/north-carolina-provider). Other source sites are not yet assigned to a DA site. Both source sites are bot-protected, so imports rely on cached snapshots. All NC-specific CSS is scoped under body.north-carolina so it doesn't leak into other sites. Data-driven blocks (Prior Auth Lookup, Forms Accordion, Table News Archive) still read bundled sample JSON until real services are connected.

Sprint scope

Focus areas agreed with the Elevance team for the current sprint (from the program kickoff, September 11 2026):

  • Healthy Blue NC provider — full site elevance-nc Migrate provider.healthybluenc.com/north-carolina-provider and its sections onto the elevance-nc site, inclusive of the 3 API calls: search, form index, and drug lookup. Done: all 47 pages imported and published; search is mocked; the form index and drug lookup blocks are built on sample JSON. Remaining: visual-parity issues from QA, and connecting the real data services.
  • Generate a page from Figma + Word Produce a page from a Figma design and a Word document. Source site TBD, based on the Figma/Word sample provided by the Elevance team.
  • Simply Healthcare DSNP dual-plans page Migrate choose.simplyhealthcareplans.com/medicare/shp/fl/dsnp/dual-plans/index with a dynamic phone number.
Open items. About 30 open QA issues on the NC site, mostly link styling, spacing, and 404s or 403s on links that point to the source site (see GitHub issues). We still need the Figma + Word sample and a published PA-code dataset for Prior Auth Lookup. New blocks also need to be registered in the DA Library so authors can insert them.
