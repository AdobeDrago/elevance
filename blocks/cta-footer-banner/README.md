# cta-footer-banner

Custom block: a full-width call-to-action band with a heading, a paragraph, and one button.

## Authoring (Document Authoring)

Model: `standalone`

A single-column block table with three rows:

| CTA Footer Banner |
|---|
| Heading text |
| Paragraph text |
| [Button label](https://example.com/target) |

- **Row 1:** heading. Plain text becomes an `h2`; a heading styled in DA keeps its level.
- **Row 2:** paragraph. Inline formatting and links are kept.
- **Row 3:** a real hyperlink. The link text is the button label and the URL is its target.
  If there is no link in this row, no button is shown.
